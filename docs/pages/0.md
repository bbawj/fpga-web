# Welcome to the FPGA webserver

This content is served to you from an FPGA with a few caveats:

- There are reverse proxies for TLS, IP masking etc.
- The images are hosted elsewhere and linked via urls

This project is still WIP, and more improvements are in the pipeline. New updates will be made available here, directly from the FPGA itself.
